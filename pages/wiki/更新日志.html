最后更新：二〇二六年九月一日

说明 本页面记录刺玫会 Wiki 自建站以来的所有重要更新。每次更新按时间倒序排列，便于追溯项目演进历程。

二〇二六年九月

九月一日

  • 新增 Wiki 板块，将教学文档、乱写文档、净标计划从「关于」移入「Wiki」分类。
  • 新增 关于Wiki 页面，系统说明 Wiki 的定位、内容范围、与服务器的关系及参与方式。
  • 新增 Wiki 更新日志 页面（本页），记录所有版本变更。
  • 新增 icons.js 独立文件，实现图标短代码功能（[icon:中文名] 自动渲染为图片）。
  • 新增 公会档案 板块扩充，完成逆熵公会档案页面编写。
  • 完成净标计划页面编写，确立 Wiki 视觉规范标准。
  • 明确网站图标为工作台图案。
  • 导航栏登录功能已注释，保留备用，移动端同步注释。

九月二日

  • 完成“野人偷吃保险”人物志页面编写（修正神权管理员为“冷月齐晓轩”）。
  • 完成“小王不嘻嘻”人物志及“逆熵”公会档案页面编写。
  • 完成“与枝沐霜”人物志页面编写。
  • 完成“游商”、“自由主义”公会档案内容的补充与状态更新（统一使用“隐退”描述停止活动的公会）。
  • 完成站内搜索功能开发（搜索框位于导航栏，支持Ctrl+K快捷键）。

九月三日

  • 发布《重要通知》公告页面，对管理事务受理范围与响应优先级作出调整。

九月五日

  • 完成 Markdown 渲染支持（marked.js），Wiki 页面现支持 .md 文件编写与渲染。
  • 完成 Markdown教程.md 页面编写，作为玩家内容创作的入门指南。
  • 新增 自定义内容 板块，用于存放无法归入现有板块的玩家提交内容。
  • 完成 Markdown 代码块样式适配，确保 .md 文件中代码块与 HTML 页面风格统一。
  • 优化手机端搜索面板体验（全屏覆盖、滚动锁定、输入同步）。
  • 修复语录作者名字颜色在白色主题下不可见的问题。
  • 修复移动端搜索框不居中的问题。
  • 修复移动端搜索结果列表滑动穿透问题。

九月六日

  • 完成板块结构重组：公告与管理规定合并为「规章」，关于与Wiki合并为「关于」，板块总数从 9 个精简至 7 个。
  • 完成 data.js 重构，实现侧边栏与卡片分类的同步更新。
  • 完成导航栏品牌图标替换（从 favicon.png 升级为高清工作台图片 Crafting_Table.png）。
  • 完成字体方案优化：中文使用系统字体，英文保留 Pixelify Sans 像素风格。
  • 完成页面内“最后更新于 X 分钟前”功能的 API 集成与测试。
  • 完成 CSS 样式清理与合并，消除重复定义导致的样式冲突。

二〇二六年八月

八月三十日

  • 刺玫会 Wiki 正式上线，完成基础框架搭建（index.html / style.css / script.js / data.js）。
  • 发布《刺玫会服务器游玩规定（修订版）》（V2.0）。
  • 发布《刺玫会服务器商店运营的个人指导建议》。
  • 新增 公告 板块，首批收录 游玩规定V2.0 与 服务器性质通告。
  • 新增 处理报告 板块，首批收录 禺密封禁报告、三体人团伙封禁报告 等。
  • 新增 工作日志 板块，记录 8.25 至 8.30 的管理工作。
  • 新增 人物志 板块，完成 弘桀孤影行、南极洲丶刺玫、赤月、小草zombie、曾面正面、方解石 六位人物页面。
  • 新增 关于 板块，包含 管理组介绍、加入我们、刺玫本设。
  • 新增 公会档案 板块，收录服务器历史上的公会信息，首批录入 刺枚教 与 末影秩序。
